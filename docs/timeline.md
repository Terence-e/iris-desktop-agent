# Timeline

[← Back to the overview](../README.md)

Built in short, intense sessions with Claude Code. Each phase had acceptance criteria and had to pass its tests before the next phase started.

```mermaid
timeline
    title October 2026
    8 Oct : Home-lab assistant - router, encrypted memory, guards, monitoring, cloud backup, phone access
    10 Oct : Assistant "Phase 1" - calendar agent, reminders, travel and clashes, moves with Undo, bookings, study slots, digests, phone approvals, voice
           : Iris phases 0-3 - scaffold, screen Q&A, glass bubble, computer use with the safety layer
    11 Oct : Iris phases 4-11 - Gmail, web search, job watcher, ChatGPT and Claude via their CLIs, app window, custom agents, memory, commands, files, pictures, voice
           : Renamed Sidekick to Iris; Linux port and USB installers
    12 Oct : Laptop running Iris on Linux Mint; self-update; problem reports and events through the cloud; shared memory and chats; speed work (easy 1-1.5 s)
    13 Oct : Groq as a fast free backup (plus Whisper, read-aloud and an injection check); key sync between computers; usage shared; Logs page
    14 Oct : Smoother glass; log fix; computers asking each other (step 1)
```
